## 🚀 GitHub-қа жариялау нұсқауы

### 1. GitHub аккаунт ашыңыз
[github.com](https://github.com) сайтына кіріп, тіркеліңіз.

### 2. Жаңа репозиторий жасаңыз
- **"New repository"** батырмасын басыңыз
- Repository name: `altyn-tech-website` (немесе кез-келген атау)
- **"Public"** деп таңдаңыз
- **"Create repository"** басыңыз

### 3. Файлдарды жүктеңіз
```bash
# Терминалда:
git init
git add .
git commit -m "Initial commit: Altyn Tech website"
git branch -M main
git remote add origin https://github.com/СІЗДІҢ_АТТЫҢЫЗ/altyn-tech-website.git
git push -u origin main
```

### 4. GitHub Pages арқылы жариялаңыз
1. Репозиторийіңізге кіріңіз
2. **Settings** → **Pages** бөліміне өтіңіз
3. **Source**: `Deploy from a branch`
4. **Branch**: `main` → `/root` → **Save**
5. 2-3 минут күтіңіз

### 5. Сілтемеңіз дайын!
```
https://СІЗДІҢ_АТТЫҢЫЗ.github.io/altyn-tech-website/
```

## ⚡ Netlify арқылы жариялау (тезірек)

1. [netlify.com](https://netlify.com) сайтына кіріңіз
2. **"Add new site"** → **"Deploy manually"**
3. `biznes-sayt` бумасын тартып апарыңыз (drag & drop)
4. Бірнеше секунд ішінде сайтыңыз дайын!
